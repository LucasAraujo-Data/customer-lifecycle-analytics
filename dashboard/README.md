# Power BI Dashboard

The Customer Lifecycle Analytics dashboard has been completed and published.

## Interactive Dashboard

[View the Interactive Power BI Dashboard](https://app.powerbi.com/view?r=eyJrIjoiY2EwYmQ5NTAtNGNhZC00MjdlLWI4MTMtMTU4MjBkNDBiOGUxIiwidCI6ImJiZTBmNmVjLTZjNGQtNGMxMi05YjdkLWUyYTEzNWE2Yjk5NSJ9)

The dashboard contains five pages:

1. **Executive Overview** — Revenue trends, customer activity, and key business metrics.
2. **Customer Segmentation** — RFM analysis and exploratory K-Means clustering.
3. **Churn Analysis** — Predictive model performance and customer churn risk.
4. **Customer Insights** — Customer value, risk distribution, and retention opportunities.
5. **Methodology** — Data sources, processing, modeling techniques, and limitations.

## Power BI File

`Customer_Lifecycle_Analytics.pbix`

The Power BI Desktop file contains the report pages, visualizations, data model, and DAX measures.

## Notes

- The dashboard uses the historical UCI Online Retail II dataset.
- Churn predictions are evaluated on the September 2011 holdout cohort.
- Historical revenue at risk does not represent projected revenue loss.
- The interactive dashboard can be accessed without installing Power BI Desktop.
